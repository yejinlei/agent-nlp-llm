🌐 BERT 预训练任务 · 互动演示

BERT 之所以强，是因为它用两个自监督任务在海量无标注文本上"自己教自己"：一个学词与上下文的关系（MLM），一个学句子与句子的关系（NSP）。下面你可以亲手"造"一次训练样本。

① MLM 掩码语言模型 · 15% 的三种玩法

BERT 随机挑 15% 的 token 来预测。但这 15% 不是全换成 [MASK]，而是又分成三份：80% 换 [MASK]、10% 换随机词、10% 保持不变。为什么这么绕？下面亲手点一下就懂了。

为什么 80/10/10 而不是全 [MASK]？ 因为训练时能看到 [MASK]，但下游微调时输入里根本没有 [MASK]——这个"训练/推理不一致"会让模型学偏。混入 10% 随机词 + 10% 原词，逼模型对任何 token 都保持上下文感知，而不是只在看到 [MASK] 时才动脑。这是一个典型的"训练策略为部署服务"的设计。

② 为什么必须"双向"看上下文

同一个词在不同上下文里意思完全不同。BERT 的 Encoder 同时看左右两边，所以能区分下面这些情况。对比 GPT 只能看左边。

提示： 左边红区是 GPT 能看到的范围（只到目标词之前），右边蓝区是 BERT 能看到的范围（左右全看）。这就是为什么 BERT 适合"理解类"任务（分类/NER/问答），GPT 适合"生成类"任务。

③ NSP 下一句预测 · 句子关系学习

NSP 任务喂给模型两个句子，判断第二句是不是真的跟在第一句后面。正样本从原文相邻取，负样本从别的文档随机抓。这让模型学会理解句子之间的逻辑关系（因果、顺承、转折），对问答和推理任务很关键。

历史插曲： 后来 RoBERTa 的论文发现 NSP 任务其实没啥用，去掉它只用 MLM、训练更久，效果反而更好。所以现在主流模型基本只保留 MLM（或它的变体）。这说明"预训练任务不是越多越好，要看它是否真的逼模型学有用的表示"。

④ 输入表示：三个 Embedding 相加

BERT 的每个 token 最终输入 = 词嵌入 + 位置嵌入 + 段嵌入，三个相加。段嵌入（Segment）就是为 NSP 服务的，用来区分第一句和第二句。

三个特殊 token 的作用： [CLS] 放在句首，它的最终向量被当作"整句表示"用于分类；[SEP] 用来分隔句子（NSP 需要）；[MASK] 是 MLM 要预测的占位符。BertEmbeddings 层做的就是这三张表查出来相加，再过 LayerNorm + Dropout。
