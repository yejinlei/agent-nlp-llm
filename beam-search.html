🔍 集束搜索演示

贪心搜索每步只选概率最高的词，容易走进死胡同（局部最优）。Beam Search 每步保留 top-k 个候选序列，最终选全局概率最高的——集束越宽，搜索越全面，但计算量也越大。

📐原理

Beam size = 1（贪心）

每步只选概率最高的 1 个词。速度快，但一旦某步选错就无法回头，经常生成重复或不通顺的文本。

Beam size = 3~5（常用）

每步保留 3~5 个最有希望的候选序列继续扩展。计算量增加，但输出质量显著提升，是机器翻译的标配。

Beam size 大（穷举近似）

集束越大越接近全局最优，但计算量和内存开销线性增长。太大的 beam 反而可能导致输出过于"安全"和通用。

注意： Beam Search 找的是近似最优序列，不是采样——它没有随机性，同样输入会得到同样输出。要生成有创造性的文本，应该用温度采样+top-k/top-p，而不是 beam search。
