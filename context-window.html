4️⃣ 因果掩码 Causal Mask（P84）

可见（权重正常计算） 被掩码（注意力权重=-∞）
为什么要掩码？P84：训练 GPT 时，位置 2 的 token 必须通过位置 1、2 预测位置 3，不能让它"偷看"位置 3 以后的未来词。实现方式：softmax 前把上三角（不含对角线）减去一个很大的数（-1e9），softmax 后这些位置变成 0。对角线保留 → 一个 token 可以"看见自己"。
