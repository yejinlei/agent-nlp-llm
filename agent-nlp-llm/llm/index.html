🎯NLP是什么

自然语言处理（Natural Language Processing, NLP）目标是让计算机理解和生成人类语言，是人工智能最重要的分支之一，是搜索引擎、机器翻译、智能客服、语音助手、内容推荐背后的核心技术。

💡 通俗理解：NLP就是给计算机装"耳朵"和"嘴巴"——耳朵听懂人类说的话/写的文字是什么意思（NLU自然语言理解），嘴巴生成人类能看懂的文字回复（NLG自然语言生成）。

NLP的难度来自三个层面：

  • 歧义性：同一个词/句子在不同上下文意思完全不同（"我去开门"vs"门开了"，"苹果"是水果还是公司）
  • 创造性：人类语言可以无限组合，永远有新的说法、新的词汇出现，不可能靠穷举覆盖
  • 知识性：理解语言需要海量世界知识和常识（"今天很冷"意味着要穿厚衣服，计算机不知道冷和穿衣服的关系）

70年来NLP经历了三次范式跃迁：规则匹配 → 统计模型 → 深度学习/Transformer，下面按时间顺序一个个讲透。

abcN-gram语言模型 核心基础

N-gram是统计语言模型的基石，核心思想来自马尔可夫假设：一个词出现的概率只依赖于它前面的N-1个词。简单高效，在工业界用了几十年，今天的大模型本质上也是N-gram的终极进化（只不过N非常大、用神经网络建模概率）。

$$ P(w_1,w_2,...,w_n) = \prod_{i=1}^n P(w_i | w_{i-N+1},...,w_{i-1}) $$

其中N=1是Unigram（不考虑上下文），N=2是Bigram（只看前1个词），N=3是Trigram（看前2个词，传统工业界最常用）。

N值选型对比

N值模型特点适用场景
N=1Unigram不考虑上下文，每个词独立，效果最差简单关键词匹配
N=2Bigram只看前1个词，效果一般，数据稀疏问题轻短文本快速预测
N=3Trigram看前2个词，传统工业界最常用，平衡效果和稀疏度输入法、搜索引擎补全
N≥44-gram+上下文更长，效果更好，但数据稀疏指数级严重有海量语料的场景

从零手搓N-gram（30行Python实现）

from collections import defaultdict
import math

# 训练语料
corpus = ["我 今天 去 超市 买 了 一瓶 可乐".split(),
          "我 昨天 去 超市 买 了 一瓶 矿泉水".split(),
          "小明 去 超市 买 了 一袋 薯片".split()]

# 统计Bigram计数
counts = defaultdict(lambda: defaultdict(int))
unigram = defaultdict(int)
for sent in corpus:
    for i in range(1, len(sent)):
        counts[sent[i-1]][sent[i]] += 1
        unigram[sent[i-1]] += 1

# 加一平滑，预测下一个词
def predict_next(prev_word, vocab_size=1000):
    probs = {}
    total = unigram[prev_word] + vocab_size
    for w in counts[prev_word]:
        probs[w] = (counts[prev_word][w] + 1) / total
    return sorted(probs.items(), key=lambda x:-x[1])

# 测试："买了"后面接什么
print(predict_next("了"))  
# 输出 [('一瓶', 0.666...), ('一袋', 0.333...)]
坑点：N-gram最大问题是数据稀疏——训练语料里没出现过的词对概率为0，必须做平滑；而且N越大需要的语料量指数级增长，所以传统NLP很少用到N>5的情况。

🕸️HMM隐马尔可夫模型 序列标注经典

HMM是序列标注的经典模型，广泛用于中文分词、词性标注、命名实体识别(NER)、语音识别等任务。核心思想是：我们看到的是观测序列（比如句子里的每个字），背后有一个隐藏的状态序列（比如这个字是词的开头/中间/结尾），我们要通过观测序列推断最可能的隐藏状态序列。

💡 通俗理解：就像你看不到屋子里的人在干什么（隐状态），只能通过窗户看到影子（观测值），通过影子的变化推断屋子里的人在做什么——HMM就是做这个推断的算法。

$$ Viterbi: \delta_t(j) = \max_i \delta_{t-1}(i) \cdot a_{ij} \cdot b_j(o_t) $$

Viterbi算法用动态规划一步步找概率最大的路径，就是HMM解码的核心。

从零手搓Viterbi分词

import numpy as np

# BMES标签：B词首 M词中 E词尾 S单字词
states = ['B', 'M', 'E', 'S']
# 简化转移概率和发射概率（实际训练语料统计得到）
trans_p = {'B':{'E':-0.5, 'M':-0.8}, 'M':{'M':-0.5, 'E':-0.8},
           'E':{'B':-0.5, 'S':-0.8}, 'S':{'S':-0.6, 'B':-0.7}}

def viterbi(sentence):
    T = len(sentence)
    delta = [{} for _ in range(T)]
    path = {}
    # 初始化
    for s in states:
        delta[0][s] = -1 if s in ['B','S'] else -999
        path[s] = [s]
    # 递推
    for t in range(1, T):
        new_path = {}
        for s in states:
            max_p, prev_st = -999, None
            for ps in states:
                p = delta[t-1][ps] + trans_p.get(ps,{}).get(s,-999)
                if p > max_p: max_p, prev_st = p, ps
            delta[t][s] = max_p
            new_path[s] = path[prev_st] + [s]
        path = new_path
    # 回溯最优路径
    best_prob = max(delta[T-1].values())
    best_state = max(delta[T-1], key=delta[T-1].get)
    return path[best_state]

print(viterbi("南京市长江大桥"))

📊Word2Vec 词向量 深度学习里程碑

2013年Tomas Mikolov提出的Word2Vec是NLP进入深度学习时代的里程碑，它把每个词映射成一个低维稠密向量（比如300维），让词有了语义——向量距离近的词语义也相近，可以做"国王-男人+女人≈女王"这种语义类比。


(One-Hot) 隐藏层
(词向量) 输出层(Softmax)
预测上下文词概率 V×N 嵌入矩阵 V个词V维向量 N=300维

Word2Vec有两种架构：CBOW用上下文预测中心词，训练更快；Skip-gram用中心词预测上下文，对小语料和罕见词效果更好。为了解决Softmax计算太慢的问题，用负采样：每次只更新几个负样本，不用算整个词表。

从零手搓Word2Vec Skip-gram+负采样（简化版）

import numpy as np

class SimpleWord2Vec:
    def __init__(self, vocab_size, embed_size=100):
        self.W1 = np.random.randn(vocab_size, embed_size) * 0.01 # 输入嵌入
        self.W2 = np.random.randn(embed_size, vocab_size) * 0.01 # 输出权重
    
    def train(self, center_idx, context_idx, neg_idxs, lr=0.01):
        # 前向
        h = self.W1[center_idx]
        u_pos = self.W2[:, context_idx] @ h
        u_neg = self.W2[:, neg_idxs].T @ h
        # 梯度更新（简化负采样损失）
        sigma_pos = 1/(1+np.exp(-u_pos))
        sigma_neg = 1/(1+np.exp(-u_neg))
        # 更新W2和W1，省略具体梯度实现...
        return -np.log(sigma_pos) - np.sum(np.log(1-sigma_neg))

# 训练完成后W1就是我们要的词向量，可以做语义类比
训练出来的词向量可以做很神奇的语义运算：向量(国王) - 向量(男人) + 向量(女人) ≈ 向量(女王)，说明词向量真的学到了语义关系，而不只是词共现。

⏳LSTM 长短期记忆网络 RNN进化版

RNN循环神经网络处理序列时会遇到严重的梯度消失问题：序列长了之后，早期的信息梯度传不到后面，相当于"记不住"很久以前的内容。LSTM通过门控机制解决这个问题，可以记住长距离依赖，在Transformer出来之前是NLP的标配模型。

💡 通俗理解：LSTM相当于一条"传送带"（细胞状态），上面有三个门：
遗忘门：决定扔掉哪些没用的旧信息
输入门：决定把哪些新信息写进传送带
输出门：决定基于传送带内容输出什么
通过门的开关控制，重要信息可以一直保留在传送带上不丢失，解决了长距离记忆问题。

$$ f_t = \sigma(W_f [h_{t-1},x_t] + b_f) \quad \text{遗忘门} $$ $$ i_t = \sigma(W_i [h_{t-1},x_t] + b_i) \quad \text{输入门} $$ $$ \tilde{C}_t = \tanh(W_C [h_{t-1},x_t] + b_C) \quad \text{候选态} $$ $$ C_t = f_t * C_{t-1} + i_t * \tilde{C}_t \quad \text{更新细胞状态} $$ $$ o_t = \sigma(W_o [h_{t-1},x_t] + b_o) \quad \text{输出门} $$ $$ h_t = o_t * \tanh(C_t) \quad \text{输出} $$

从零手搓LSTM Cell（PyTorch）

import torch
import torch.nn as nn

class LSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        # 四个门的权重合并成一个矩阵，一次计算完
        self.W = nn.Linear(input_size + hidden_size, 4*hidden_size)
    
    def forward(self, x, state):
        h_prev, c_prev = state
        combined = torch.cat([x, h_prev], dim=-1)
        gates = self.W(combined)
        i, f, o, g = gates.chunk(4, dim=-1)
        
        i = torch.sigmoid(i)       # 输入门
        f = torch.sigmoid(f)       # 遗忘门
        o = torch.sigmoid(o)       # 输出门
        g = torch.tanh(g)          # 候选态
        
        c_next = f * c_prev + i * g  # 更新细胞状态
        h_next = o * torch.tanh(c_next) # 计算输出
        return h_next, (h_next, c_next)

🔥Self-Attention 自注意力机制 Transformer核心

自注意力是Transformer和今天所有大模型的核心，它解决了RNN/LSTM不能并行计算、长距离依赖弱的问题：序列中每个词都可以直接和其他所有词计算注意力权重，一步就能看到整个序列的信息，而且完全并行计算，速度比RNN快很多。

💡 通俗理解：自注意力就像你读书的时候划重点——读每一句话的时候，你会回头看前面哪些相关的内容，给重要的内容更高权重，不重要的内容忽略掉。Q/K/V三个矩阵就像：
Q(Query查询)：我现在要找什么信息
K(Key键)：我这里有什么信息
V(Value值)：我实际的内容
Q和K算相似度得到注意力权重，再对V加权求和就是当前位置的输出。

$$ \text{Attention}(Q,K,V) = \text{Softmax}\left( \frac{QK^T}{\sqrt{d_k}} \right) V $$

除以$\sqrt{d_k}$是因为点积结果会随着维度变大而变大，Softmax会进入梯度极小的区域，除以根号维度做缩放。

从零手搓Self-Attention（PyTorch）

import torch
import torch.nn as nn
import torch.nn.functional as F

class ScaledDotProductAttention(nn.Module):
    def __init__(self, d_k):
        super().__init__()
        self.d_k = d_k
    
    def forward(self, Q, K, V, mask=None):
        # 1. Q和K点积算相似度
        scores = torch.matmul(Q, K.transpose(-2,-1)) / torch.sqrt(torch.tensor(self.d_k, dtype=torch.float32))
        # 2. 因果mask：把未来位置设为-∞，Softmax后权重为0
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        # 3. Softmax归一化成权重
        attn_weights = F.softmax(scores, dim=-1)
        # 4. 对V加权求和得到输出
        output = torch.matmul(attn_weights, V)
        return output, attn_weights
多头注意力就是把Q/K/V拆成h个头，每个头独立算注意力，最后拼起来——不同的头可以学不同的注意力模式，有的头学语法、有的头学指代、有的头学语义关系，效果比单头好很多。

🧬Transformer架构 新时代基石

2017年Google发表《Attention Is All You Need》提出Transformer，完全抛弃RNN循环结构，只用注意力机制搭建模型，并行计算能力强、长距离依赖效果好，直接开启了大模型时代——今天所有GPT、LLaMA、Qwen等大模型都是基于Transformer的Decoder架构。

完整Transformer包含编码器（Encoder）和解码器（Decoder）两部分：BERT只用编码器做理解任务，GPT只用解码器做生成任务。

Transformer完整架构图

💡 Encoder是双向注意力，每个词能看到前后所有词，适合做理解任务（分类/标注）；Decoder第一层是掩码自注意力，每个词只能看到前面已经生成的词，不能看未来，适合做自回归生成任务。

$$ PE_{(pos,2i)} = \sin\left( \frac{pos}{10000^{2i/d_{model}}} \right), \quad PE_{(pos,2i+1)} = \cos\left( \frac{pos}{10000^{2i/d_{model}}} \right) $$

正弦余弦位置编码公式，每个位置得到一个d_model维的位置向量，和词嵌入相加

从零手搓Transformer Encoder Block

import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def forward(self, x, mask=None):
        B, T, C = x.shape
        q = self.W_q(x).view(B, T, self.n_heads, self.d_k).transpose(1,2)
        k = self.W_k(x).view(B, T, self.n_heads, self.d_k).transpose(1,2)
        v = self.W_v(x).view(B, T, self.n_heads, self.d_k).transpose(1,2)
        scores = q @ k.transpose(-2,-1) / (self.d_k**0.5)
        if mask is not None: scores = scores.masked_fill(mask==0, -1e9)
        attn = F.softmax(scores, dim=-1)
        out = (attn @ v).transpose(1,2).contiguous().view(B,T,C)
        return self.W_o(out)

class EncoderBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff):
        super().__init__()
        self.attn = MultiHeadAttention(d_model, n_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model))
        self.norm2 = nn.LayerNorm(d_model)
    
    def forward(self, x, mask=None):
        x = x + self.attn(self.norm1(x), mask) # 注意力+残差+Norm
        x = x + self.ffn(self.norm2(x))     # FFN+残差+Norm
        return x
注意残差连接是Pre-Norm结构：先做LayerNorm再进注意力/FFN，再加残差，训练更稳定，和GPT/BERT实际用的结构一致。

🎯BERT预训练模型

2018年Google提出BERT（Bidirectional Encoder Representations from Transformers），开启NLP预训练时代：用大规模无标注语料预训练一个双向Transformer编码器，然后在下游任务上微调，11项NLP任务刷爆SOTA，把NLP效果提升了一个大台阶。

BERT vs GPT 架构对比图

BERT两个核心预训练任务：

  • MLM掩码语言模型：随机盖住15%的词，其中80%替换成[MASK]，10%替换成随机词，10%保留原词，让模型预测盖住的词，强迫模型学习双向上下文语义。
  • NSP下一句预测：给模型两个句子，50%概率是真的上下文，50%概率是随机选的句子，让模型判断是不是上下句，学习句子间关系。（后来RoBERTa发现NSP任务没什么用就去掉了）
