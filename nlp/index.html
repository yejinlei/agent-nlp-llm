🎯 这是什么

自然语言处理（Natural Language Processing, NLP）是人工智能领域研究如何让计算机理解和生成人类语言的方向。本模块覆盖传统NLP和深度学习NLP的完整知识体系，从最基础的文本预处理到Transformer预训练模型，每个算法都遵循「论文→理论→实现→实战」四层闭环学习路径。

NLP的核心挑战在于：人类语言天生具有歧义性、上下文依赖和常识性，同样的词语在不同语境下含义千差万别。从规则方法到统计方法再到深度学习方法，NLP的发展史就是一部不断缓解这些问题的技术演进史。

① 文本预处理
分词算法（最大匹配/BPE/WordPiece）
📄 论文背景

BPE（Byte Pair Encoding）最早是数据压缩算法，2016年Sennrich等人在论文《Neural Machine Translation of Rare Words with Subword Units》中将其引入NLP，解决OOV（未登录词）问题。中文分词经典算法包括正向最大匹配（FMM）、逆向最大匹配（BMM）、双向最大匹配。

📚 理论原理

正向最大匹配（FMM）：从左到右扫描句子，每次取最长的词典匹配词。

BPE：统计语料中相邻字符对的频率，每次合并频率最高的字符对，直到达到预设词表大小。不需要提前训练分词器，天然解决OOV问题。

WordPiece：BERT使用的分词算法，类似BPE但基于概率选择合并（合并使语言模型困惑度下降最多的对）。

💻 核心实现
def forward_max_match(sentence, word_dict, max_len=5):
    result = []
    i = 0
    while i < len(sentence):
        matched = False
        for l in range(min(max_len, len(sentence)-i), 0, -1):
            word = sentence[i:i+l]
            if word in word_dict:
                result.append(word)
                i += l
                matched = True
                break
        if not matched:
            result.append(sentence[i])
            i += 1
    return result
🚀 实战要点
  • 中文场景：通用领域用jieba，专业领域（医疗/法律）建议自定义词典
  • 大模型时代：直接用模型自带的tokenizer（BPE/Byte-level BPE），不需要额外分词
  • 工程坑点：停用词表不要直接用通用表，要根据任务调整（情感分析不要去掉否定词）
文本归一化（TF-IDF/去停用词/词干提取）
📄 论文背景

TF-IDF由Jones在1972年《A Statistical Interpretation of Term Specificity and its Application in Retrieval》中提出，是信息检索领域最经典的词权重算法，至今在搜索、关键词提取、文本分类场景仍广泛使用。

📚 理论原理

$$TF-IDF(t,d) = TF(t,d) \times IDF(t)$$

TF（词频）：词t在文档d中出现的频率；IDF（逆文档频率）：$\log(N/df(t))$，N是总文档数，df(t)是包含词t的文档数。核心思想：一个词在当前文档出现越多，在其他文档出现越少，对这个文档越重要。

💻 核心实现
from collections import Counter
import math

def tf_idf(corpus):
    N = len(corpus)
    df = Counter()
    tf_list = []
    for doc in corpus:
        tf = Counter(doc)
        tf_list.append(tf)
        for word in set(doc):
            df[word] += 1
    idf = {w: math.log(N/(df[w]+1)) for w in df}
    result = []
    for tf in tf_list:
        doc_tfidf = {w: tf[w]/sum(tf.values()) * idf[w] for w in tf}
        result.append(doc_tfidf)
    return result
🚀 实战要点
  • TF-IDF适合短文本关键词提取、简单文本分类基线、搜索引擎初筛
  • 缺点：无法理解语义，"苹果"手机和"苹果"水果无法区分，不考虑词序
  • 工程坑点：要做停用词过滤，否则"的""是"这类停用词权重会很高
② 统计NLP
N-gram 语言模型
📄 论文背景

N-gram是统计语言模型的基础，由Shannon在1948年《A Mathematical Theory of Communication》中提出，基于马尔可夫假设：下一个词的出现只依赖于前面n-1个词。在深度学习时代之前，N-gram一直是语音识别、机器翻译、输入法的核心技术。

📚 理论原理

$$P(w_1,w_2,...,w_n) = \prod_{i=1}^n P(w_i|w_{i-n+1},...,w_{i-1})$$

常用的是Bi-gram（n=2）和Tri-gram（n=3）。概率通过最大似然估计从语料中统计：$P(w_i|w_{i-1}) = C(w_{i-1},w_i)/C(w_{i-1})$。需要加平滑（如加1平滑、Good-Turing平滑）解决零概率问题。

💻 核心实现
from collections import defaultdict, Counter

def train_bigram(corpus):
    bigram_counts = defaultdict(Counter)
    unigram_counts = Counter()
    for sent in corpus:
        sent = [''] + sent + ['']
        for i in range(1, len(sent)):
            bigram_counts[sent[i-1]][sent[i]] += 1
            unigram_counts[sent[i-1]] += 1
    # 计算概率
    prob = defaultdict(dict)
    for w_prev in bigram_counts:
        total = unigram_counts[w_prev]
        for w_curr, cnt in bigram_counts[w_prev].items():
            prob[w_prev][w_curr] = cnt / total
    return prob
🚀 实战要点
  • N越大，模型越准但越稀疏，一般n最大到5
  • 现在仍然在输入法联想、文本纠错、低资源场景基线中使用
  • 工程坑点：OOV问题严重，必须做平滑，否则未见过的词对会导致概率为0
HMM 隐马尔可夫模型
📄 论文背景

HMM是序列标注的经典模型，1980年代被引入NLP用于词性标注、命名实体识别、语音识别。核心假设：观测序列由隐藏的状态序列生成，满足马尔可夫性（当前状态只依赖前一个状态）。

📚 理论原理

HMM有三个核心问题：

  1. 评估问题：给定模型参数和观测序列，计算出现概率 → 前向算法
  2. 解码问题：给定模型参数和观测序列，找最可能的隐藏状态序列 → 维特比（Viterbi）算法（NLP最常用）
  3. 学习问题：给定观测序列，估计模型参数 → Baum-Welch算法（EM算法的特例）

维特比算法是动态规划：$\delta_t(i) = \max_{j} \delta_{t-1}(j) a_{ji} b_i(o_t)$，记录路径回溯即可得到最优序列。

💻 核心实现
def viterbi(obs, states, start_p, trans_p, emit_p):
    V = [{}]
    path = {}
    for s in states:
        V[0][s] = start_p[s] * emit_p[s][obs[0]]
        path[s] = [s]
    for t in range(1, len(obs)):
        V.append({})
        newpath = {}
        for s in states:
            (prob, state) = max((V[t-1][s0] * trans_p[s0][s] * emit_p[s][obs[t]], s0) for s0 in states)
            V[t][s] = prob
            newpath[s] = path[state] + [s]
        path = newpath
    (prob, state) = max((V[-1][s], s) for s in states)
    return prob, path[state]
🚀 实战要点
  • 中文分词、词性标注、简单NER的经典基线，速度极快
  • 缺点：只能依赖前一个状态，无法捕捉长距离依赖；特征工程需要人工设计
  • 工程坑点：训练时要做概率平滑，否则会出现0概率导致维特比路径错误
CRF 条件随机场
📄 论文背景

2001年Lafferty等人在《Conditional Random Fields: Probabilistic Models for Segmenting and Labeling Sequence Data》中提出，解决了HMM的输出独立假设问题，是序列标注领域在深度学习之前的SOTA，至今在BERT+CRF的组合中仍广泛使用。

📚 理论原理

CRF是判别式模型，直接对条件概率P(Y|X)建模，线性链CRF的概率：

$$P(y|x) = \frac{1}{Z(x)} \exp\left(\sum_{i,k} \lambda_k t_k(y_{i-1},y_i,x,i) + \sum_{i,l} \mu_l s_l(y_i,x,i)\right)$$

核心优势：可以加入任意全局特征（比如前后几个词的特征、词的前缀后缀），不需要严格的独立性假设，标签之间有转移约束，不会出现B-PER后面接I-LOC这种不合理标签。解码同样用维特比算法。

💻 核心实现

核心思想：在HMM维特比基础上，加入自定义特征函数，训练用L-BFGS优化对数似然。实战中直接用`crfsuite`或`sklearn-crfsuite`即可，不需要从零实现。

import sklearn_crfsuite
crf = sklearn_crfsuite.CRF(algorithm='lbfgs', c1=0.1, c2=0.1, max_iterations=100)
# X是每个词的特征集合：[{'word': '我', 'postag': 'r', 'prefix': '我'}, ...]
# y是标签序列：['B-PER', 'I-PER', 'O', ...]
crf.fit(X_train, y_train)
🚀 实战要点
  • 序列标注任务上BERT+CRF比纯BERT效果好，因为CRF可以约束标签转移合法性
  • 缺点：训练速度慢，特征工程依赖人工，长距离依赖捕捉能力还是有限
  • 工程坑点：特征工程非常重要，通常要加：当前词、前后词、前后缀、词性、是否大写、是否数字等几十种特征才能出好效果
③ 词表示与神经网络
Word2Vec 词向量
📄 论文背景

2013年Mikolov等人在《Efficient Estimation of Word Representations in Vector Space》中提出，是NLP从稀疏表示转向稠密表示的里程碑。第一次让词向量可以高效在大规模语料上训练，并且向量具有语义线性关系（国王-男人+女人≈女王）。

📚 理论原理

两种架构：

  • CBOW：用上下文词预测中心词，速度快，适合小语料
  • Skip-gram：用中心词预测上下文词，效果好，适合大语料和低频词

核心优化技巧：负采样（Negative Sampling）和层次Softmax，把原来|V|大小的Softmax变成二分类，训练速度提升几个数量级。

💻 核心实现（Skip-gram负采样）
# 简化版Word2Vec Skip-gram + 负采样核心逻辑
def skip_gram_step(center_word, context_word, neg_words, W_in, W_out, lr=0.025):
    # center_word: (dim,), 输入向量
    # 正样本
    score = W_out[context_word] @ W_in[center_word]
    grad = sigmoid(score) - 1
    W_out[context_word] -= lr * grad * W_in[center_word]
    grad_center = grad * W_out[context_word]
    # 负样本
    for nw in neg_words:
        score = W_out[nw] @ W_in[center_word]
        grad = sigmoid(score)
        W_out[nw] -= lr * grad * W_in[center_word]
        grad_center += grad * W_out[nw]
    W_in[center_word] -= lr * grad_center
🚀 实战要点
  • 实战直接用`gensim.models.Word2Vec`，不需要自己实现
  • 参数经验：window=5-10，dim=100-300，min_count=5，负采样数=5-10
  • 缺点：词和向量一一对应，无法解决一词多义；无法处理OOV；是静态向量，上下文不变
RNN/LSTM/GRU 循环神经网络
📄 论文背景

RNN在1990年代被提出，但因为梯度消失问题无法训练长序列；1997年Hochreiter等人提出LSTM（Long Short-Term Memory），通过门控机制解决长距离依赖问题；2014年Cho等人提出GRU，简化了LSTM的门，参数更少速度更快。

📚 理论原理

LSTM三个门：遗忘门$f_t$、输入门$i_t$、输出门$o_t$，以及细胞状态$c_t$：

$$f_t = \sigma(W_f[h_{t-1},x_t]+b_f)$$

$$i_t = \sigma(W_i[h_{t-1},x_t]+b_i)$$

$$o_t = \sigma(W_o[h_{t-1},x_t]+b_o)$$

$$c_t = f_t c_{t-1} + i_t \tanh(W_c[h_{t-1},x_t]+b_c)$$

$$h_t = o_t \tanh(c_t)$$

核心思想：细胞状态像一个传送带，通过门控制哪些信息保留、哪些信息遗忘、哪些信息新增，梯度可以在细胞状态上畅通传播，缓解梯度消失。

💻 核心实现（LSTM Cell）
def lstm_cell(x, h_prev, c_prev, Wf, Wi, Wo, Wc, bf, bi, bo, bc):
    concat = torch.cat([h_prev, x], dim=-1)
    f = torch.sigmoid(concat @ Wf + bf)  # 遗忘门
    i = torch.sigmoid(concat @ Wi + bi)  # 输入门
    o = torch.sigmoid(concat @ Wo + bo)  # 输出门
    c_tilde = torch.tanh(concat @ Wc + bc) # 候选细胞
    c = f * c_prev + i * c_tilde
    h = o * torch.tanh(c)
    return h, c
🚀 实战要点
  • 在Transformer之前是NLP序列建模标配，现在大部分场景被Transformer取代，但在低资源小模型、实时序列场景仍有使用
  • 缺点：天生串行无法并行，长距离（>100步）依赖仍然捕捉不好，训练速度慢
  • 工程坑点：训练时要做梯度裁剪（clip_grad_norm）防止梯度爆炸；多层LSTM要做dropout；双向LSTM（BiLSTM）比单向效果好很多
④ 注意力与Transformer
Seq2Seq + Bahdanau注意力
📄 论文背景

2014年Sutskever等人提出Seq2Seq（编码器-解码器）架构用于机器翻译，但固定长度上下文向量成为瓶颈；2015年Bahdanau等人在《Neural Machine Translation by Jointly Learning to Align and Translate》中提出注意力机制，第一次让解码器可以动态关注输入序列的不同位置，大幅提升翻译效果，是Transformer注意力的前身。

📚 理论原理

核心思想：解码器在生成每个词时，计算当前解码器状态和所有编码器输出的相似度，得到注意力权重，加权求和得到上下文向量，再用这个向量生成当前词：

$$e_{ti} = a(s_{t-1}, h_i)$$

$$\alpha_{ti} = \text{softmax}(e_{ti})$$

$$c_t = \sum_i \alpha_{ti} h_i$$

其中$a$是对齐模型，通常是一个小的前馈神经网络。

💻 核心实现
class BahdanauAttention(nn.Module):
    def __init__(self, hidden_size):
        super().__init__()
        self.Wa = nn.Linear(hidden_size, hidden_size)
        self.Ua = nn.Linear(hidden_size, hidden_size)
        self.Va = nn.Linear(hidden_size, 1)
    def forward(self, query, keys):
        scores = self.Va(torch.tanh(self.Wa(query.unsqueeze(1)) + self.Ua(keys)))
        weights = torch.softmax(scores.squeeze(-1), dim=-1)
        context = torch.bmm(weights.unsqueeze(1), keys).squeeze(1)
        return context, weights
🚀 实战要点
  • 解决了Seq2Seq固定长度瓶颈，长句子翻译效果大幅提升
  • 注意力权重可视化可以看到词对齐效果，有一定可解释性
  • 缺点：计算量是序列长度平方级，长序列慢；还是基于RNN无法并行
Self-Attention 自注意力
📄 论文背景

2017年Vaswani等人在《Attention Is All You Need》中提出缩放点积自注意力，是Transformer的核心组件，完全抛弃RNN/CNN，仅靠注意力就可以建模序列关系，开启了大模型时代。

📚 理论原理

缩放点积注意力公式：

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中Q（查询）、K（键）、V（值）都是输入向量通过线性变换得到的。除以$\sqrt{d_k}$是为了防止点积值过大导致softmax饱和梯度消失。多头注意力是把Q/K/V分成多份分别做注意力，再拼接起来，可以捕捉不同类型的关系（语法/语义/共指等）。

💻 核心实现
def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2,-1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask==0, -1e9)
    attn_weights = torch.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights
🚀 实战要点
  • 优点：可以并行计算，每个位置直接和所有位置交互，长距离依赖捕捉能力极强
  • 缺点：计算量和显存都是序列长度平方级，长序列（>4k）需要线性注意力、FlashAttention等优化
  • 工程坑点：Decoder端必须加causal mask防止看到未来信息；数值稳定性很重要，要注意除以根号d_k
Transformer 架构
📄 论文背景

同上述《Attention Is All You Need》，完整Transformer架构包含编码器和解码器各6层，由多头自注意力、前馈网络、残差连接、层归一化、位置编码组成。BERT只用编码器，GPT只用解码器。

📚 理论原理

核心组件：

  • 位置编码：因为注意力没有顺序信息，需要加正弦/余弦位置编码（或可学习位置编码）注入位置信息
  • 残差连接+LayerNorm：Pre-Norm结构$x + \text{Attention}(\text{LayerNorm}(x))$，稳定深层网络训练
  • 前馈网络FFN：每个位置独立的两层MLP，通常是升维4倍再降维
💻 核心实现（Transformer Block）
class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff):
        super().__init__()
        self.attn = MultiHeadAttention(d_model, n_heads)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.GELU(), nn.Linear(d_ff, d_model)
        )
        self.ln1 = nn.LayerNorm(d_model)
        self.ln2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(0.1)
    def forward(self, x, mask=None):
        x = x + self.dropout(self.attn(self.ln1(x), mask=mask))
        x = x + self.dropout(self.ffn(self.ln2(x)))
        return x
🚀 实战要点
  • 现在所有大模型都是Transformer的变体，核心架构没有变
  • 预训练+微调范式取代了之前的任务特定架构，一个架构可以解决所有NLP任务
⑤ 预训练语言模型
BERT
📄 论文背景

2018年Google在《BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding》中提出，开启了NLP预训练大模型时代，在11个NLP任务上刷榜SOTA。

📚 理论原理

编码器架构，双向注意力，两个预训练任务：

  • MLM（掩码语言模型）：随机mask 15%的词，预测被mask的词，让模型学习双向上下文表示
  • NSP（下一句预测）：判断两个句子是否是连续的，学习句子间关系（后续证明作用不大，RoBERTa去掉了）

🗂️ 六大技术分支

① 文本预处理

分词、清洗、归一化、TF-IDF特征提取，是所有NLP任务的基础，数据预处理决定了效果上限。

② 统计NLP

N-gram、HMM、CRF，统计时代的经典模型，在特定场景（如中文分词、低资源）仍然有实用价值，BERT+CRF仍是序列标注常用方案。

③ 词表示与神经网络

从One-Hot到Word2Vec、GloVe静态词向量，再到RNN/LSTM/TextCNN序列模型，深度学习时代的NLP基础。

④ 注意力与Transformer

Bahdanau注意力、自注意力、Transformer完整架构，是现代所有NLP和大模型的基石，必须彻底搞懂。

⑤ 预训练语言模型

BERT（双向理解）、GPT（自回归生成）两大预训练路线，开启NLP大模型时代，微调即可解决大部分任务。

⑥ 核心任务实战

文本分类、序列标注、机器翻译、文本摘要、信息抽取、问答系统、对话系统，工业界常见落地方向。

📚 精选算法档案

点击家族树中每个算法即可查看完整四层内容，下面是核心算法快速入口：

Word2Vec 词向量

里程碑式工作，把词语映射到低维稠密向量空间，使词语具有语义计算能力，是深度学习NLP的基础。核心贡献是提出了高效的负采样训练方法，让大规模语料训练词向量成为可能。缺点是静态向量无法解决一词多义。

LSTM 长短期记忆网络

通过门控机制解决了RNN梯度消失问题，能够捕捉长距离依赖，在Transformer之前统治NLP近20年。三个门（遗忘门/输入门/输出门）的设计是经典，至今在时间序列、低资源场景仍有广泛应用。

Self-Attention 自注意力

Transformer的核心，现代AI的基石。完全抛弃循环结构，通过Q/K/V点积计算任意两个位置之间的依赖，并行性好，长距离建模能力强。所有大模型都是基于自注意力构建的，必须深入理解其数学原理和实现细节。

Mikolov et al., 2013 · Word2Vec原文

词向量经典工作，开启深度学习NLP时代。

《BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding》
Devlin et al., 2018 · BERT原文

预训练语言模型里程碑，刷爆11个NLP任务榜单。

《Neural Machine Translation by Jointly Learning to Align and Translate》
Bahdanau et al., 2015 · 注意力机制开山作

第一次把注意力机制引入Seq2Seq，是Transformer注意力的前身。

🎯 实战案例

电商评论情感分析

技术栈：BERT + 线性分类头

坑点：要处理网络用语、表情符号、否定转折（"不是不好用，是非常难用"），数据标注质量比模型重要，垂直领域用领域预训练模型比通用模型效果好5%以上。

简历信息抽取

技术栈：BERT + BiLSTM + CRF 命名实体识别

坑点：实体嵌套问题（"阿里巴巴公司"既是公司名，"阿里巴巴"也可能单独出现），CRF层对标签合法性约束很重要，要设计丰富的规则做后处理。
