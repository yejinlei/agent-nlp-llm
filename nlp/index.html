🎯 NLP 是什么

自然语言处理（Natural Language Processing）是人工智能的核心分支，目标是让计算机理解、生成人类语言。它是一门交叉学科，融合了语言学、统计学、机器学习、计算机科学。

和计算机视觉不同，语言是离散的符号系统，有歧义、有上下文依赖、有文化背景，这使得NLP长期被认为是AI皇冠上的明珠。从1950年图灵测试到今天的ChatGPT，NLP的发展走过了70年历程。

NLU 自然语言理解

让计算机"懂"语言：文本分类、情感分析、命名实体识别、阅读理解、信息抽取

NLG 自然语言生成

让计算机"写"语言：机器翻译、文本摘要、对话系统、问答系统、内容生成

🔪 预处理四步曲

原始文本不能直接喂给模型，必须经过标准化预处理。这是NLP的基本功，看似简单但直接影响最终效果。

1️⃣ 分词 Tokenization

把连续文本切分成有意义的词/子词单元。中文分词比英文难，因为没有天然空格分隔。主流分词算法有：基于词典的正向最大匹配、基于统计的HMM/CRF分词、现在主流的BPE/SentencePiece子词分词。

import jieba
text = "我爱自然语言处理"
print(list(jieba.cut(text)))  # ['我', '爱', '自然语言', '处理']

2️⃣ 清洗与归一化

去除HTML标签、特殊符号、多余空格，统一大小写、繁简转换、全角半角转换，数字/日期归一化（如把"100%"、"百分之百"统一）。

3️⃣ 去停用词

去掉"的、了、吗、啊、the、a、is"这类没有实际语义的高频虚词，减少噪声和计算量。但在某些任务（如句法分析、对话系统）中不能随便去停用词。

4️⃣ 词表示

把词转换成计算机能处理的数字向量：从最早的One-Hot，到TF-IDF，再到Word2Vec词向量，演进了几十年。

🔤 N-gram 语言模型

N-gram是统计语言模型的基石，核心思想来自马尔可夫假设：一个词出现的概率只依赖于它前面的N-1个词。简单高效，在工业界用了几十年，今天的大模型本质上也是N-gram的终极进化（只不过N非常大、用神经网络建模）。

$$P(w_1,w_2,...,w_n) = \prod_{i=1}^n P(w_i | w_{i-N+1},...,w_{i-1})$$

N的选择

N值模型特点
N=1Unigram不考虑上下文，每个词独立，效果最差
N=2Bigram只看前1个词，效果一般，数据稀疏问题轻
N=3Trigram看前2个词，传统工业界最常用，平衡效果和稀疏度
N≥44-gram+上下文更长，效果更好，但数据稀疏指数级严重

平滑技术

N-gram最大的问题是数据稀疏：训练语料里没出现过的词对概率为0。所以需要加平滑：加一平滑（Laplace）、古德-图灵平滑、Kneser-Ney平滑。

🔗 HMM · 隐马尔可夫模型

HMM是序列标注任务（分词、词性标注、命名实体识别、语音识别）的经典模型。它是生成式模型，建模隐含状态序列生成观测序列的过程。

HMM有两个基本假设：

  1. 齐次马尔可夫假设：当前隐含状态只依赖于前一个隐含状态
  2. 观测独立性假设：当前观测只依赖于当前隐含状态

HMM的三个经典问题

问题含义算法
概率计算问题给定模型λ和观测序列O，计算P(O|λ)前向算法 / 后向算法
解码问题给定模型λ和观测O，找最可能的隐含状态序列Viterbi算法
学习问题给定观测序列O，估计模型参数λ=(A,B,π)Baum-Welch算法（EM）

HMM在2000-2010年是NLP序列标注的主流，缺点是观测独立性假设太强，无法利用长距离特征，后来被CRF和神经网络模型取代。

🧭 Viterbi 解码 · 互动演示

Viterbi算法是HMM的解码核心，本质是动态规划：用动态规划求概率最大的路径（最优状态序列），每一步都保留到当前状态的最大概率和回溯指针。

📐 CRF · 条件随机场

CRF是判别式序列模型，解决了HMM观测独立性假设太强的问题。CRF直接建模P(Y|X)，可以任意添加特征（前后词、词性、前缀后缀等），在序列标注任务上效果显著优于HMM。

在BERT出来之前，BiLSTM-CRF是序列标注的黄金组合：BiLSTM提取上下文特征，CRF学习标签转移约束（比如B后面不能跟S、M后面不能跟S），解决标签合法性问题。

📊 Word2Vec · 词向量革命

2013年Tomas Mikolov提出的Word2Vec是NLP深度学习时代的开山之作。它把每个词映射到一个低维稠密向量（通常100-300维），让词之间有了"语义距离"：

$$向量(国王) - 向量(男人) + 向量(女人) \approx 向量(女王)$$

这种语义线性关系震惊了整个NLP社区，从此词向量成为NLP的标准输入。

🧠 想真正搞懂词向量是怎么"学"出来的？
从共现矩阵 → PMI → SVD → CBOW → 负采样，全链路含公式推导、可跑代码和交互可视化。
进入 Word2Vec 从零 →

📌 书2第2–4章的核心链条（一句话版）

  • 共现矩阵：统计每个词周围出现哪些词，把"上下文"变成可计算的数字。
  • PMI 点互信息：PMI = log₂(P(x,y)/P(x)P(y))，把"the 到处共现"的高频噪音压下去，只留真正的语义关联。
  • SVD 降维：把稀疏的高维矩阵压成稠密低维向量，语义相近的词自然聚在一起。
  • 负采样：把"从十万词里选一个"偷换成"判断真假"的二分类，计算量从 O(V) 降到 O(K+1)。

两种训练方式

CBOW 连续词袋

用上下文词预测中心词。训练速度快，对高频词效果好。

Skip-gram 跳字模型

用中心词预测上下文词。对低频词效果好，训练稍慢，是Word2Vec默认推荐。

# Word2Vec Skip-gram 核心实现（简化版）
class SkipGram(nn.Module):
    def __init__(self, vocab_size, embed_size):
        super().__init__()
        self.in_embed = nn.Embedding(vocab_size, embed_size)
        self.out_embed = nn.Embedding(vocab_size, embed_size)
    
    def forward(self, center, context, negatives):
        # 中心词向量
        center_vec = self.in_embed(center)
        # 正样本：上下文词
        context_vec = self.out_embed(context)
        # 负采样损失
        pos_score = torch.bmm(context_vec, center_vec.unsqueeze(2)).squeeze()
        neg_score = torch.bmm(self.out_embed(negatives).neg(), 
                              center_vec.unsqueeze(2)).squeeze()
        return -F.logsigmoid(pos_score).sum() - F.logsigmoid(neg_score).sum()

🎯 负采样：把 100 万分类变成 5 分类

原始 Skip-gram 要对 整个词表（几十万～上百万） 做 softmax，算一步就要遍历所有词，慢到无法训练。书2《深度学习入门2：自制框架》第4章的精髓就是用 负采样（Negative Sampling） 把问题偷换成"二分类"：

不给模型"从 100 万词里挑对的"，而是问它"这个词对是不是真实共现的？"
正样本 = 真实上下文词；负样本 = 随机抽几个"噪声词"。于是每步只算 1 + k 个（k 通常 5~10）Sigmoid，计算量与词表大小彻底解耦。
import numpy as np

def get_negative_samples(corpus, target_id, num_neg, vocab_size):
    """书2第4章：从语料中按词频随机抽负样本，避开目标词本身"""
    negs = []
    while len(negs) < num_neg:
        s = np.random.choice(corpus)          # corpus 是所有出现过的词 id 数组
        if s != target_id:
            negs.append(s)
    return np.array(negs)

# 损失 = 正样本"越接近1越好" + 负样本"越接近0越好"
def sigmoid(x): return 1 / (1 + np.exp(-x))

def negative_sampling_loss(score_pos, score_neg):
    # score_pos 是正样本点积，score_neg 是负样本点积
    loss = -np.log(sigmoid(score_pos)) - np.sum(np.log(sigmoid(-score_neg)))
    return loss

📐 怎么判断两个词"像不像"？—— 余弦相似度

词向量有长度（模），直接比距离会受词频影响。我们只关心方向是否一致，所以用夹角余弦——这正是 king - man + woman ≈ queen 能成立的度量基础：

cos(a, b) = (a · b) / (‖a‖ · ‖b‖)　∈ [−1, 1]
= 1 方向完全相同（同义）；= 0 正交无关；= −1 完全相反。除以两个模长就抹掉了"词频"带来的长度差异。
def cosine_similarity(x, y):
    """书2第3章的相似度计算，逐元素实现，不用现成库"""
    nx = x / np.sqrt(np.sum(x ** 2))     # 单位化：除以自身模长
    ny = y / np.sqrt(np.sum(y ** 2))
    return np.dot(nx, ny)

# 实战：找出与 "king" 最相近的词
def most_similar(query_id, word_vecs, word_to_id, top=5):
    sims = [(w, cosine_similarity(word_vecs[query_id], word_vecs[i]))
            for w, i in word_to_id.items() if w != list(word_to_id)[query_id]]
    return sorted(sims, key=lambda t: t[1], reverse=True)[:top]

🧠 LSTM · 长短期记忆网络

🔁 想从零推导 RNN / LSTM / Attention？
BPTT 梯度消失数学根源 → LSTM 四个门逐个拆解 → seq2seq 翻译 → Attention 取代记忆，全含交互演示。
进入 RNN 从零 →

RNN循环神经网络天然适合处理序列数据，但存在严重的梯度消失/梯度爆炸问题，无法捕捉长距离依赖。1997年提出的LSTM通过门控机制解决了这个问题，成为2013-2017年NLP的主力模型。

LSTM三个门的作用

门作用公式
遗忘门决定细胞状态中哪些信息需要丢弃$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$
输入门决定哪些新信息存入细胞状态$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$
输出门决定输出什么值（基于细胞状态）$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$

LSTM虽然能捕捉长距离依赖，但本质还是循环结构，无法并行计算，长距离（超过几百字）效果还是会衰减，后来被自注意力机制彻底取代。

⚠️ 梯度消失的数学根源：连乘的衰减

书2《深度学习入门2：自制框架》第5～6章专门拆解了这个问题。RNN 反向传播要沿时间一步步回传，梯度里会出现一连串雅可比矩阵的连乘：

∂L/∂h₁ = ∂L/∂hT · ∏t=2..T ∂ht/∂ht−1
每一步的雅可比若"谱范数 < 1"，连乘 T 次就指数级趋近 0（梯度消失，学不到远距离依赖）；若 > 1 则指数爆炸（梯度爆炸，训练发散）。这就是 RNN 记不住长句的根本原因。

✂️ 截断反向传播（Truncated BPTT）：工程上的折中

理论要对整个序列反向传播，但序列可能上万步，显存和时间都扛不住。书2的做法是：把长序列切成固定长度的"块"，块内完整反向传播，块与块之间只传递隐藏状态、不跨块回传梯度。代价是丢失超长依赖，收益是显存可控、可并行流水。这正是所有 RNN 类模型训练的标配。

class SimpleRnnlm:
    """书2第5章：截断 BPTT —— 状态在块间延续，梯度只在块内回传"""
    def __init__(self, vocab_size, wordvec_size, hidden_size, bptt_len=10):
        V, D, H = vocab_size, wordvec_size, hidden_size
        self.bptt_len = bptt_len                     # 每个块的长度
        # 书里的 Xavier 初始化：让前向信号方差不随层数爆炸
        self.Wx  = np.random.randn(V, H) / np.sqrt(V) * 0.01
        self.Wh  = np.random.randn(H, H) / np.sqrt(H)
        self.b   = np.zeros(H)

    def forward(self, xs, hs):                       # xs: (B, T, V)
        B, T, _ = xs.shape
        # 关键：h 的"接力棒"从上一块的状态 hs[0] 开始，而不是每次清零
        for t in range(T):
            hs[t+1] = np.tanh(xs[:, t] @ self.Wx + hs[t] @ self.Wh + self.b)
        return hs

# 训练循环的核心：块内算梯度，块间只搬运状态

💡 LSTM 为什么能缓解？ 它用遗忘门把连乘换成了"加法式累积"（细胞状态 C 的更新是 C_t = f_t·C_{t−1} + i_t·C̃_t），梯度沿 C 回传时是乘上接近 1 的 f，而不是一长串小于 1 的连乘，所以记忆能延续几百步。但门控再巧也改不了"串行"的本质，最终仍被可并行的自注意力取代。

🎯 注意力机制

2014年Bahdanau在Seq2Seq机器翻译中首次引入注意力机制，彻底解决了固定长度上下文瓶颈：解码每个词时，模型可以动态"看"编码器所有位置的输出，给不同位置分配不同权重。

$$Attention(Q,K,V) = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

这就是著名的缩放点积注意力，是Transformer的核心。Q(Query)是查询向量，K(Key)是键向量，V(Value)是值向量：通过Q和K的点积计算相似度，softmax归一化得到注意力权重，再对V加权求和得到输出。

注意力最革命性的地方是：可以并行计算所有位置的依赖关系，一步到位看到整个序列，距离不依赖路径长度，彻底解决了RNN的长距离问题和并行问题。

🧱 Transformer · 注意力就是一切

2017年Google发表《Attention Is All You Need》，提出Transformer架构，完全抛弃循环和卷积，只用自注意力机制，效果更好、训练更快，直接开启了大模型时代。

Transformer Encoder 核心组件

  1. 多头自注意力：多组Q/K/V并行计算不同子空间的注意力，最后拼接
  2. 位置编码：因为没有循环，需要给词加入位置信息（正弦/余弦编码或可学习位置编码）
  3. 残差连接 + LayerNorm：解决深层网络梯度消失，稳定训练
  4. 前馈神经网络FFN：每个位置独立过两层MLP，做非线性变换
# 缩放点积注意力 从零实现
def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    # Q乘K转置，除以根号d_k缩放，点积太大softmax会饱和
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    attn_weights = F.softmax(scores, dim=-1)
    return torch.matmul(attn_weights, V), attn_weights

🌐 BERT · 预训练语言模型

2018年Google提出BERT（Bidirectional Encoder Representations from Transformers），开启了NLP预训练范式：先在大规模无标注语料上预训练一个通用模型，再在下游任务上微调，横扫11项NLP任务SOTA。

BERT两个预训练任务

MLM 掩码语言模型

随机遮住15%的词，让模型预测被遮住的词。真正实现双向上下文编码，而不是像GPT那样只能看到左边。

NSP 下一句预测

给模型两个句子，判断第二句是不是第一句的下一句。让模型理解句子间关系，服务于问答、推理等任务。

BERT是Encoder路线的顶峰，而GPT是Decoder路线，后来的发展证明：生成式任务上Decoder路线（GPT）更有潜力，这就是大语言模型的方向。

    prediction = torch.argmax(outputs.logits, dim=-1)
print("预测结果:", "正面" if prediction == 1 else "负面")

源码阅读路径建议

  1. BertEmbeddings: 词嵌入+位置嵌入+段嵌入
  2. BertSelfAttention: 多头自注意力实现，Q/K/V线性变换
  3. BertLayer: 自注意力+FFN+残差+LayerNorm
  4. BertEncoder: 多层BertLayer堆叠
  5. 各类任务头：分类、NER、问答等
