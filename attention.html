🎯 注意力机制：让模型学会"该看哪"

一句话里，"它"到底指小猫还是老鼠？注意力机制让模型自己学会在理解某个词时该重点参考哪些词，而这个"关注权重"是训练出来的，不需要人写规则。

①直觉：开会的比喻

理解一句话，就像开一场会。Self-Attention 的意思是：每个人（每个词）同时听所有人发言，然后自己决定该重点记谁的、忽略谁的。

Query（我想问什么）

当前词的"提问"。比如"它"在想：我要理解自己指谁，该找哪个名词？

Key（我是什么）

其他词亮出的"身份标签"。"小猫""老鼠"都会亮出"我是名词"。

Value（我能给什么内容）

其他词实际贡献的信息。匹配度高的 Key，它的 Value 就被重点采纳。

图书馆类比： Query 是你的检索关键词，Key 是每本书的书名标签，Value 是书的内容。你拿关键词去和所有书名比对（QKᵀ），哪本书标签最匹配，就重点读那本（加权求和 Value）。整个过程可微分，所以能端到端训练。

为什么需要它？ 在 RNN/LSTM 时代，信息要沿着时间一步步传递，句子一长，前面的信息就被"稀释"甚至遗忘了（长距离依赖瓶颈）。注意力让任意两个位置直接相连，距离不管多远，权重都能学出来。

②数学：缩放点积注意力

这是 Transformer 的核心公式，一个式子搞定"匹配 + 加权"：

\( \text{Attention}(Q,K,V)=\text{softmax}\!\left(\dfrac{QK^{\top}}{\sqrt{d_k}}\right)V \)

逐步拆解：

步骤表达式在干嘛
① 算匹配度\( QK^{\top} \)每个 Query 和所有 Key 做点积，得到"像不像"的分数矩阵
② 缩放\( \div\sqrt{d_k} \)维度越大点积越大，除以 \( \sqrt{d_k} \) 防止 softmax 进饱和区、梯度消失
③ 归一化\( \text{softmax}(\cdot) \)把分数转成加起来等于 1 的权重
④ 加权求和\( \cdot\,V \)按权重把各词的 Value 混合起来，得到输出

为什么要"多头"？

一个注意力头只能学一种关注模式。多头 = 多个头并行，各自关注不同关系（一个看语法主谓、一个看指代、一个看修饰），再把结果拼起来：

\( \text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W^{O},\quad \text{head}_i=\text{Attention}(QW_i^{Q},KW_i^{K},VW_i^{V}) \)
复杂度警告： 注意力要对每对位置算分数，复杂度是 \( O(n^2) \)——序列翻倍，计算量和显存翻 4 倍。这就是长文本处理昂贵、也是 FlashAttention / 稀疏注意力 / 线性注意力等优化方法存在的根本原因。

③代码：从零实现缩放点积注意力

import torch, torch.nn as nn, torch.nn.functional as F, math

def scaled_dot_product_attention(q, k, v, mask=None):
    # q: [B, h, T_q, d_k]  k: [B, h, T_k, d_k]  v: [B, h, T_k, d_v]
    d_k = q.size(-1)

    # ① 匹配度矩阵：[B,h,T_q,T_k]
    scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k)   # ② 缩放

    # 因果掩码：自回归生成时，第 t 个位置不能看到未来
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))

    # ③ softmax 归一化（沿最后一维，即对所有 Key）
    attn = F.softmax(scores, dim=-1)

    # ④ 加权求和得到输出
    return torch.matmul(attn, v), attn

# —— 自测 ——
B, h, T, d = 2, 8, 16, 64
q, k, v = [torch.randn(B, h, T, d) for _ in range(3)]
# 下三角因果掩码
mask = torch.tril(torch.ones(T, T)).view(1, 1, T, T)
out, attn = scaled_dot_product_attention(q, k, v, mask)
print(out.shape, attn.shape)   # [2,8,16,64] [2,8,16,16]
print(attn[0,0,0])          # 第0个位置只能看到自己，权重全在 index 0
💡 masked_fill(mask==0, -inf) 是因果注意力的关键：softmax 后 -inf 变成 0，模型就"看不见"未来了。这也是 GPT 能逐词生成的技术前提。

④实战：优化、成本与争议

加速：FlashAttention

传统实现要把 \( n\times n \) 的分数矩阵写进显存。FlashAttention 用分块 + 在线 softmax，不落地完整矩阵，显存和速度都大幅改善，是现代训练的标配。

省 KV 缓存：MQA / GQA

生成时每步都要缓存历史 Key/Value，长上下文显存吃紧。让多个 Query 头共享一组 KV（MQA/GQA），能在几乎不掉效果的前提下省下大量显存。

注意力 = 解释性？

人们一度以为注意力权重就是"模型在看哪"的证据。但后续研究表明注意力权重与最终预测的因果关系并不直接，不能简单当作解释。可视化有启发，但别奉为真理。

长文本的下一站

滑动窗口注意力、稀疏注意力、线性注意力、状态空间模型（Mamba）都在试图绕开 \( O(n^2) \) 的代价。这是当前最活跃的研究方向之一。
