① 为什么需要 Transformer？

在 Transformer 之前，处理序列的主力是 RNN / LSTM。它们像人读句子一样，一个字一个字往后读，把前面读到的内容压进一个『记忆状态』里传递下去。这带来两个致命问题：

❌ 问题一：没法并行

第 100 个词必须等前 99 个词算完才能算。GPU 有几千个核心却只能干等——训练一个模型要几周。

❌ 问题二：记不住长距离

信息挤在一个固定长度的状态里，传到后面就衰减。"猫"和隔了 50 个词的"它"之间，RNN 很难建立联系。

Transformer 的解法极其大胆：干脆不要循环结构。让每一个词同时和句子里所有其他词直接对话，一次性算出『每个词该关注谁』。这不仅天然并行（一句话的注意力可以一次矩阵乘法算完），还让任意两个词之间的距离都变成 1 步——不管隔多远，触手可及。

② 注意力的直觉：查字典

别被公式吓到，注意力的本质就是一次带权重的查字典。

📖 图书馆比喻：你（Query）想去图书馆找一本关于"机器学习"的书。图书馆的每本书都有标签（Key）。你拿自己的需求去和每本书的标签比对——越匹配的书，你借来看的权重越大。最后你带回家的，是所有书内容的加权合集（Value）。标签完全无关的书，你几乎不看（权重≈0）。

放到句子里：处理"它"这个代词时，"它"的 Query 会去和句中所有词（包括"猫"）的 Key 比对，发现"猫"最匹配，于是把"猫"的 Value 大量吸收进来——模型就"知道"这个"它"指的是猫。这就是指代消解靠注意力自动完成的原理。

③ Q / K / V 到底是什么？

同一个输入向量 x，乘上三个不同的可学习权重矩阵，就得到了 Q、K、V 三种角色。记住这张表，永远不混：

符号角色一句话记忆公式
Query查询"我在找什么？"Q = X · WQ
Key键"我能提供什么标签？"K = X · WK
Value值"如果我被选中，我贡献什么内容？"V = X · WV

注意力做的事：Q 和 K 点积得到"匹配分"，softmax 归一化成"关注权重"，再用权重去加权求和 V。整个过程一句话：

$$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
输出形状和输入 X 完全一致 —— 所以你可以一层层堆叠，堆几百层都行。

④ 为什么要除以 √dₖ？

这是最常被问、也最容易被忽略的细节。当向量维度 d 变大时，Q 和 K 点积的方差也会随之变大——结果可能变成几十甚至几百的大数。Softmax 遇到大数会"一家独大"：最大值的概率接近 1，其余接近 0，梯度几乎消失，训练就学不动了。

除以 √dₖ 后，点积的方差被"压"回 1 附近，softmax 的分布保持柔和、有梯度。这是 Transformer 能稳定训练的关键细节之一。

⑤ 因果掩码：不许偷看答案

GPT 是自回归模型——它要预测下一个词。但训练时如果让它在算第 3 个词的时候"看到"了第 4 个词的真实答案，那它就是在作弊，学不到真本事。

解法是因果掩码（Causal Mask）：在注意力分数矩阵上，把"未来"的位置（上三角）全部置成 −∞。softmax 之后这些位置的概率就变成 0。第 i 个词只能看见 1…i。

被掩码的分数 = −∞　→　exp(−∞) = 0　→　未来词权重为 0
掩码矩阵是一个下三角全 1、上三角全 0 的矩阵，配合 `masked_fill` 一行代码搞定。

⑥ 多头注意力：让模型同时"多线程思考"

一次注意力只能学到一种"关注模式"。但语言里同时存在语法关系、指代关系、语义相似……多头注意力就是把 d_model 维切成 h 份，每份独立算一次注意力，最后拼接、再过一个线性层。每个头相当于一个"专家"，各盯一种关系。

GPT-3 用了 96 个头。下面的实验室用 4 种不同"性格"的头（局部头、全局头、语法头、指代头）在真实计算它们的注意力分布，你一眼看懂"多头"到底在干嘛。

⑦ 位置编码：给每个词贴上"坐标"

注意力有个"缺陷"：它对词的顺序完全不敏感。"猫追狗"和"狗追猫"喂进去，不叠位置信息的话结果一模一样。所以必须在嵌入向量里"注入"位置信息。

原始 Transformer 用正弦/余弦位置编码：每个位置 pos 用一个不同频率的波来编码，偶数维用 sin、奇数维用 cos。好处是不用训练、还能外推到更长的序列。

$$PE_{(pos,2i)}=\sin\!\left(\frac{pos}{10000^{2i/d}}\right),\quad PE_{(pos,2i+1)}=\cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$
现代大模型（Llama、Qwen）已换成 RoPE 旋转位置编码——把位置信息"旋转"进 Q、K 向量里，外推更自然。

⑧ FFN · 残差连接 · LayerNorm

注意力块之后还有一个"前馈网络（FFN）"，以及包裹每个子层的残差连接和归一化。这三样东西共同保证模型又深又稳：

FFN

两层 MLP，中间升到 4 倍再降回。每个位置独立处理，是模型的"知识仓库"。

残差连接

y = x + Sublayer(x)。梯度能沿"高速公路"直通底层，是深层网络能训练的根本。

LayerNorm

对每个样本沿特征维归一化，不受 batch 影响，训练/推理一致。

$$\text{FFN}(x)=\text{GELU}(xW_1+b_1)W_2+b_2 \qquad \text{LN}(x)=\gamma\cdot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta$$
FFN 参数量约占一个 Transformer 块的 2/3——大模型的"大"，很大一部分在 FFN 里。

⑨ 从零实现：不调包的注意力

下面用纯 NumPy 手写一个单头因果自注意力，每一行都注释了它在算什么。你看懂这段，就看懂了 Transformer 的心脏。（右侧可点"运行"在浏览器里真实执行等价 JavaScript 版本。）

import numpy as np

def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)      # 数值稳定：先减最大值
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

class CausalSelfAttention:
    def __init__(self, d_in, d_out, context_len):
        rng = np.random.default_rng(0)
        # 三个可学习权重矩阵：Q/K/V 的"投影器"
        self.Wq = rng.normal(0, 0.1, (d_in, d_out))
        self.Wk = rng.normal(0, 0.1, (d_in, d_out))
        self.Wv = rng.normal(0, 0.1, (d_in, d_out))
        # 因果掩码：上三角为 -inf，屏蔽未来
        self.mask = np.triu(np.full((context_len, context_len), -np.inf), k=1)

    def forward(self, x):               # x: (T, d_in)
        T, _ = x.shape
        Q = x @ self.Wq                 # (T, d_out) 我要找什么
        K = x @ self.Wk                 # (T, d_out) 我能给什么
        V = x @ self.Wv                 # (T, d_out) 我贡献什么

        scores = Q @ K.T / np.sqrt(Q.shape[-1])   # (T, T) 打分 + 缩放
        scores = scores + self.mask[:T, :T]         # 加掩码，未来位变 -inf
        attn = softmax(scores, axis=-1)             # (T, T) 归一化权重
        out = attn @ V                              # (T, d_out) 加权求和
        return out, attn

# 跑一个 3 词、4 维的例子
x = np.random.default_rng(1).normal(0, 1, (3, 4))
out, attn = CausalSelfAttention(4, 4, 3).forward(x)
print("注意力权重矩阵(下三角):\n", np.round(attn, 3))

⑩ 自回归生成：GPT 是怎么"一个字一个字吐"的

训练好的语言模型输出的是一个概率分布。生成文本时，它每次只选一个词，把这个词拼回输入，再跑一次前向，再选下一个……循环往复，直到生成结束符。这个过程叫自回归（Autoregressive）。

每一步怎么选词，直接决定了输出的风格——这就是"温度"和"top-k"的用武之地。
