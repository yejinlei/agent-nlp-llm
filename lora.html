🪢 LoRA 低秩适配实验室

核心思想：冻结预训练权重 W₀，只训练两个小矩阵 B·A（秩为 r），让 h = W₀x + (α/r)·BAx。拖动滑块看 r 与 α 如何影响参数量和近似精度。

⚙️ 参数

LoRA 公式（附录E 式E.1）：
W = W₀ + ΔW = W₀ + Bd×r · Ar×d · (α/r)
· 前向时：ΔWx = B(Ax) · α/r
· 推理时可合并到 W₀，零额外开销
直觉：大模型做下游任务时，权重变化 ΔW 其实是"低秩"的（主要信息集中在少数方向上）。LoRA 不用学 d×d=1600万 参数，只学 2·d·r 个参数。

📖 附录E 的关键点

  • r 的选择：经验值 r=4~64，r 太小表达能力不足，r 太大失去参数效率。r=8 或 r=16 在多数任务已足够。
  • α 缩放：α/r 让我们在改变 r 时不必重新调学习率，常用 α=2r（即缩放因子为 2）。
  • 只在注意力投影（Wq/Wv）上用 LoRA是常见做法，MLP 层通常冻结，进一步省参数。
  • 推理合并：训练完后 ΔW = BA·α/r 可以直接加到 W₀ 上，推理和原模型完全一样快——这是 LoRA 相比 Adapter 的最大优势。
