RNN · LSTM · Attention 从零 🔁

语言是有顺序的——"猫吃鱼"和"鱼吃猫"意思完全相反。这一页把循环神经网络的主线走完：为什么 RNN 会健忘 → LSTM 四个门如何救场 → seq2seq 怎么翻译 → Attention 如何取代记忆。

🎯 一句话抓住本质

RNN 的野心是记住过去：每读一个词，就把它和"以前的记忆"揉在一起。但它有个天生的毛病——记性越远越模糊。LSTM 用"门"来解决；Attention 则干脆说：别硬记了，用到时回去查！

1. 语言模型：给一句话打分

语言模型的任务是算一句话出现的概率。用条件概率链式展开：

P(w₁,w₂,…,wₜ) = ∏ᵗ P(wₜ | w₁,…,wₜ₋₁)

翻译成人话：这句话说得通不通，等于"每个词在前面所有词的条件下出现得顺不顺"连乘起来。

怎么衡量好坏？用困惑度（Perplexity）：

PPL = eL，L 是交叉熵损失
困惑度怎么读？PPL = 10 可以理解为"模型每次预测时，在 10 个词里犹豫不定"。越小越好，1 表示每次都猜对。GPT-2 在 WikiText 上的 PPL 约为 20 左右。

2. RNN：带"记忆"的神经网络

普通前馈网络是"一次性"的，喂完就忘。RNN 加了一条循环回路：把上一时刻的隐藏状态 ht−1 也作为本时刻的输入。

ht = tanh( Wh · ht−1 + Wx · xt + b )

直观理解：ht 是一个"状态快照"，它浓缩了从句子开头到现在的所有信息。每读一个新词，这个快照就更新一次。

3. BPTT 与梯度消失（数学根源）

RNN 的反向传播要沿着时间倒着走一遍，叫 BPTT（Backpropagation Through Time）。

问题来了：当序列很长时，梯度从最后一步传回第一步，中间要连乘很多个雅可比矩阵。矩阵乘法的连乘，如果每个矩阵的"放大倍数"小于 1，最后结果就指数级衰减到 0——这就是梯度消失；反之则指数级爆炸。
∂L/∂h₁ = ∂L/∂hT · ∏t=2..T ∂ht/∂ht−1

4. Truncated BPTT：工程上的取舍

既然整条链太长，那就砍成一截一截：每次只反向传播固定长度（比如 20 步），但隐藏状态要接着传下去。这叫截断 BPTT。

✅ 好处

计算量可控、能处理任意长度文本、可以 mini-batch 并行。

⚠️ 代价

超过截断长度的依赖关系学不到。这为后来的 LSTM 和 Attention 埋下伏笔。

class RNN:
    def __init__(self, Wx, Wh, b):
        self.params = [Wx, Wh, b]
        self.grads = [np.zeros_like(Wx), np.zeros_like(Wh), np.zeros_like(b)]
        self.cache = None

    def forward(self, x, h_prev):
        Wx, Wh, b = self.params
        t = np.dot(h_prev, Wh) + np.dot(x, Wx) + b
        h_next = np.tanh(t)
        self.cache = (x, h_prev, h_next)
        return h_next
    # backward 省略：需按时间步逆序累积 dh

5. LSTM：四个门逐个拆解

LSTM 的关键创新是引入了一条独立的记忆单元 c（cell）通路，并用三个"门"来控制信息流。门就是 sigmoid 函数——输出 0～1 之间的数，0 表示"完全关闭"，1 表示"完全放行"。

🚪 遗忘门 f

决定忘掉多少旧记忆。

f = σ(x·Wxf + h·Whf + bf)

为什么重要？读到新主语时，得先清掉旧主语的记忆。

🚪 输入门 i

决定写入多少新信息。

i = σ(x·Wxi + h·Whi + bi)

新记忆 g = tanh(...)，最终 c = f⊙c_old + i⊙g。

🚪 输出门 o

决定暴露多少记忆给外部。

o = σ(...)，h = o ⊙ tanh(c)

记忆 c 是内部的，h 才是给下一层/下一时刻看的。

🧠 记忆单元 c

信息的"高速公路"。

ct = f ⊙ ct−1 + i ⊙ g

⊙ 是逐元素乘。加法路径让梯度能"无损"回传，天然缓解梯度消失。

LSTM 为什么能缓解梯度消失？关键在 ct = f⊙ct−1 + i⊙g 里的加号。反向传播时，加法节点的梯度是"原样传递"的，不会被反复乘小。只要遗忘门 f 接近 1，记忆就能沿着这条高速路走很远。

6. 梯度爆炸与梯度裁剪

梯度消失的对策是 LSTM；梯度爆炸的对策就简单粗暴多了——梯度裁剪（Gradient Clipping）：算完梯度后，如果它的范数超过阈值，就等比缩回来。

def clip_grads(grads, max_norm):
    total_norm = 0
    for grad in grads:
        total_norm += np.sum(grad ** 2)
    total_norm = np.sqrt(total_norm)

    rate = max_norm / (total_norm + 1e-6)
    if rate < 1:              # 只在超阈值时才裁剪
        for grad in grads:
            grad *= rate
    return total_norm
一行直觉："你可以走，但一步不许迈太大。"防止某个异常样本把参数一步带崩。

7. seq2seq：Encoder-Decoder 翻译

光有 RNN 还只会"接龙"。要让它做翻译（输入一句话，输出另一句话），得把两个 RNN 接起来：

📥 Encoder（编码器）

把输入序列压成一个隐藏状态 h——这就是整句话的"语义摘要"。

📤 Decoder（解码器）

拿着这个 h 当起点，一个词一个词地生成目标语言。

用 RNN 生成文本时，采用"贪心接龙"：每次取概率最高的词，再把它喂回去当下一个输入。

def generate(decoder, start_id, sample_size=20):
    text = ''
    h = None
    sampled_ids = [start_id]
    idx = start_id
    for _ in range(sample_size):
        h = decoder.forward(idx, h)          # 一步步喂回去
        idx = h.argmax                     # 贪心：取概率最高的
        sampled_ids.append(idx)
    return sampled_ids
seq2seq 的软肋：不管输入多长，Encoder 都只吐出一个固定长度的 h。输入 50 个词和 5 个词，都被压成同一个尺寸的向量——长句子必然丢信息。这就是 Attention 要解决的核心问题。

8. Attention：记忆不够，注意力来凑

Attention 的洞见极其漂亮：与其把所有信息压进一个 h，不如让 Decoder 每次生成词时，动态地从 Encoder 的每一步输出里"挑重点"。

① 算相似度

解码器当前状态和编码器每个时刻状态算内积 → 得到"关注分数"。

② softmax 归一化

分数变成权重（和为 1），代表"该看多少"。

③ 加权求和

把编码器各时刻状态按权重加权 → 得到"上下文向量"。

权重 a = softmax(相似度)　　context = Σ aᵢ · hᵢ
🎯 Attention 权重实时计算：点一个解码位置，看它把注意力分给了输入句子的哪些词

从 RNN 到 Transformer 的关键一步：Attention 证明了一件事——要捕捉长距离依赖，不一定要靠循环，靠"直接查询"反而更好、更快、还能并行。于是有了那篇《Attention Is All You Need》，也就有了今天所有的大模型。

🧭 一条主线串起来

语言模型（给句子打分）→ RNN（记住过去）→ BPTT 梯度消失（记性变差的数学根源）→ LSTM 四个门（加一条记忆高速路）→ seq2seq（翻译）→ Attention（不硬记，按需查）→ Transformer（丢开循环，全程注意力）。

每一步都是"发现上一个方法的毛病 → 想新招解决"——这正是"从零开始"最核心的思考方式：每一步都要回答"为什么需要它"。
