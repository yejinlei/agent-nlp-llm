🎯 这是什么

🧪 数学概念互动实验室

拖动滑块、点击按钮，亲眼看到抽象数学如何在信号中起作用：

🎛️ 正弦波叠加 · 傅里叶直觉

任何复杂信号都可以分解为多个正弦波之和。调节三个正弦波的频率和幅度，观察合成波形——这就是傅里叶变换的核心直觉。

f(t) = 1.0·sin(2π·2t) + 0.5·sin(2π·4t) + 0.3·sin(2π·6t)
💡当你把更多高频成分加进来，方波、锯齿波等"非光滑"波形就出现了——人声就是基频 + 大量谐波（共振峰）的叠加。

🧩 CTC 对齐直觉

CTC 引入 blank ε，允许重复字符，最终通过"去重 + 去 blank"合并出正确文本。输入一个短文本试试：

🌊 源-滤波模型

语音 = 声源（声带振动的脉冲/噪声） × 滤波器（口腔/鼻腔的共振）。拖动基频和共振峰感受区别：

男声中低音区 + 中性元音：基频 120Hz 接近成年男声，F1=500Hz 接近中央元音 /ə/。试试把 F0 拉到 220Hz 听女声、F1 拉到 800Hz 成 /a/。

📚 精选算法档案

每个算法从"直觉→数学→代码→为什么被超越"四个维度拆解：

🎤 ASR 核心算法

📊 MFCC 梅尔倒谱系数 1980s

模拟人耳梅尔刻度的特征，统治 ASR 30 年。从预加重到 DCT 倒谱的 7 步流程。

🔗 HMM 隐马尔可夫 1980s

三状态拓扑 + 发射概率 + 转移矩阵 + Viterbi 解码，传统 ASR 的基石。

⚡ CTC 连接时序分类 2006/2014

引入 blank 让输入输出长度不等时可训练，端到端 ASR 的开山之作。

🎯 Attention Seq2Seq 2015-2016

LAS / Listen-Attend-Spell，注意力对齐让"听"和"写"彻底解耦。

📢 TTS 核心算法

🌊 WaveNet 2016

自回归逐样本生成 + 扩张因果卷积，第一次让神经网络生成的语音达到自然水平。

🎼 Tacotron 2 2018

Seq2Seq 编码器-注意力-解码器 + WaveNet 声码器，开启现代神经 TTS。

⚡ FastSpeech 2 2020

非自回归 + 时长/音高/能量预测器，推理速度快 270 倍，工业首选。

🎭 VITS 2021

VAE + Flow + GAN 端到端联合训练，单模型完成"文本→波形"，开源标杆。

深度学习不是凭空出现的。很多核心思想（如帧同步、对齐、时长预测、梅尔谱中间表示）直接继承自传统方法：

📖学习提示：很多人直接跳到深度学习，遇到 CTC/Attention 的"对齐"问题时就卡住。其实传统 HMM 的 Viterbi 对齐、TTS 的时长建模，已经把这些问题想透了——学传统方法不是浪费时间，是给深度学习打地基。

🚀 5 分钟快速开始

# 安装 OpenAI Whisper
pip install -U openai-whisper

# Python 中使用（自动下载模型）
import whisper
model = whisper.load_model("base")          # tiny/base/small/medium/large
result = model.transcribe("audio.mp3", language="zh")
print(result["text"])

# 命令行一行识别
whisper audio.mp3 --model medium --language zh --output_format txt
💡Whisper 是 68 万小时多语言数据预训练的模型，中文识别推荐 medium 或 large-v3，支持自动语言检测、带时间戳输出、翻译成英文。
# 安装 ChatTTS（中文零样本 TTS 新王）
pip install ChatTTS

# 最简合成
import ChatTTS
import torch, torchaudio
chat = ChatTTS.Chat()
chat.load(compile=False)
wavs = chat.infer(["你好，欢迎来到 agent-speech 语音研究站！"])
torchaudio.save("out.wav", torch.from_numpy(wavs[0]), 24000)
⚠️开源中文 TTS 还可选择：CosyVoice（阿里）、FishSpeech、Edge-TTS（微软在线接口，免费）、PaddleSpeech（百度）。工业部署常用 VITS2 / Bert-VITS2 方案。
