LSTM vs GRU：同门不同路

介绍了 LSTM 的 3 个门 + 1 个候选 g̃；教材中也简要提到 GRU（Cho et al. 2014）用 2 个门完成相同工作，"结构更简单、计算更快、效果相当"。拖动滑块，实时对比两种门控在同一段序列里的状态差异。

🟪 LSTM（3 个门 + 1 个候选）

ft = σ(Wf·[ht-1, xt] + bf)  遗忘门
it = σ(Wi·[ht-1, xt] + bi)  输入门
g̃t = tanh(Wg·[ht-1, xt] + bg)  候选
ot = σ(Wo·[ht-1, xt] + bo)  输出门
ct = ft⊙ct-1 + it⊙g̃t
ht = ot⊙tanh(ct)

记忆单元 c 和隐藏状态 h 分离。c 像传送带，加法更新保证梯度能长距离流动，不会被链式乘性挤压。

🟦 GRU（2 个门，无独立 c）

zt = σ(Wz·[ht-1, xt])  更新门(=f+i)
rt = σ(Wr·[ht-1, xt])  重置门
h̃t = tanh(W·[rt⊙ht-1, xt])
ht = (1-zt)⊙ht-1 + zt⊙h̃t

"GRU 没有 LSTM 中那种 c 和 h 的区别，只用一个 h 同时承担两个角色。参数更少、训练更快。"

🎚️ 模拟一段 10 步序列

选择一个场景，拖动"输入信号强度"模拟这一步有多少新信息进来。观察 LSTM 的 c/h 和 GRU 的 h 如何变化。

LSTM 记忆单元 ct（传送带）
LSTM 隐藏 ht（当前输出）
GRU 隐藏 ht（同时是记忆+输出）

📊 参数对比

模型门数参数量（单层，隐藏维度 d）记忆/输出分离训练速度长依赖能力
RNN0d·(d+x) + d ≈ 2d²否快❌ 弱
GRU2（z,r）3·[d·(d+x)+d] ≈ 6d²否较快✅ 中
LSTM3（f,i,o）4·[d·(d+x)+d] ≈ 8d²✅ c 与 h 分离较慢✅✅ 强
总结："GRU 和 LSTM 性能差不多时，优先 GRU（参数少、易训）；需要超长距离依赖（如机器翻译、长文档）时 LSTM 更稳。" 不过现在 transformer 时代，两者都主要作为 baseline 出现。
